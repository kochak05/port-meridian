Port Meridian is an original top-down 2D open-world crime game: explore a city on foot and by car, steal cars, outrun the police, and complete 3 missions (Courier Run, Getaway Car, Harbor Heist) with combat, traffic, pedestrians, a wanted level, HUD and minimap.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
